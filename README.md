# SKA Adventure

A Realistic 3D Open World Multiplayer Life Simulation Game.

## Features
- Realistic 3D Open World
- City, Village, Forest, Mountains and Ocean
- Male and Female Characters
- Gmail Login
- Friends and Multiplayer
- Houses and Vehicles
- Jobs and Business
- Clothing Customization
- Hunger, Thirst and Sleep System

## Platform
Android and Web

## Technology
Three.js
Firebase
TypeScript
